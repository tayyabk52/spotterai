# Capability artwork

Owner requested imagegen illustrations to replace only the diagrams above the existing capability lists. Card copy, labels, icons, destinations, footer, and surrounding product layout stay unchanged.

Generated using the built-in image_gen tool. Original outputs remain under the Codex generated_images directory; project-ready assets live under public/images/capabilities. Optimized WebP output preserves transparency, uses 1200px width, quality 88 and alpha quality 100. These are conceptual illustrations, not product screenshots or performance evidence.

## Final prompts

### lens

Use case: stylized-concept. Asset type: premium website capability illustration for Spotter Lens market intelligence, only the artwork above an existing text list, not a whole card. Create a refined studio-rendered sculptural diagram: a central porcelain-white circular lens with concentric precision-machined teal rings, two small incoming signal beads on curved fine teal paths, and one outgoing pale teal decision bead. An understated coral pin provides one accent. Wide horizontal composition, front three-quarter view, all objects fully visible, centered within generous transparent margins, approximately 2.5:1 visual footprint. Material: satin ceramic and solid matte enamel, tactile bevels, subtle ambient contact shading, no glass. Palette restricted to teal #008080, pale teal #BBDDDE, porcelain #FAFDFD, dark teal #102A2B and a tiny coral #F8485F accent. Seamlessly composited onto a light teal website card. True transparent background. No text, numbers, labels, UI screens, charts, logos, frames, gradients, glow, scenery, or watermark. Sophisticated art-directed enterprise illustration, clean silhouette legible at 160px high.
